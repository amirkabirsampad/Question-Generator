# 🎓 سوال‌ساز هوشمند - MVP

یک ابزار ساده برای تولید سوالات آزمون از روی فایل‌های PDF با استفاده از هوش مصنوعی.

## 🚀 راه‌اندازی سریع

### 1. نصب Python
- از [python.org](https://python.org) دانلود کنید
- حتماً "Add to PATH" را تیک بزنید

### 2. کلون پروژه
```bash
git clone <repository-url>
cd question-generator-mvp
```

### 3. محیط مجازی
```bash
python -m venv venv
.\venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

### 4. نصب پکیج‌ها
```bash
pip install -r requirements.txt
```

### 5. تنظیم API Key
1. برو به [OpenAI Platform](https://platform.openai.com/api-keys)
2. یک API key بساز
3. در فایل `.env` قرار بده:
```
OPENAI_API_KEY=sk-your-actual-api-key-here
```

### 6. اجرا
```bash
python app.py
```

سپس برو به: http://localhost:5000

## 🔧 تنظیمات

### تغییر مدل AI:
در `app.py` خط 70:
```python
model="gpt-3.5-turbo"  # یا gpt-4
```

### تغییر حداکثر حجم فایل:
در `app.py` خط 16:
```python
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 16MB
```

## 🐛 عیب‌یابی

### خطای "API Key نامعتبر":
- API Key را در `.env` چک کنید
- اعتبار حساب OpenAI را بررسی کنید

### خطای "متن کافی نیست":
- PDF باید حداقل 50 کاراکتر متن داشته باشد
- از PDF های قابل جستجو استفاده کنید (نه عکس)

### خطای فونت فارسی:
- فعلاً از فونت پیش‌فرض استفاده می‌شود
- برای بهبود، فونت فارسی اضافه کنید
